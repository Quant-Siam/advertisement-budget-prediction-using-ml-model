## 🧐 Overview

In today's competitive market, allocating marketing budgets effectively is critical for maximizing Return on Investment (ROI). 

This project leverages **Supervised Machine Learning Regression techniques** to analyze historical advertising spend across multiple channels (TV, Radio, Newspaper) and predict expected product sales with high accuracy.

---

## 🎯 Key Features

- 🧹 **Data Cleaning & Preprocessing:** Advanced categorical encoding (One-Hot / Binary / Dummy Encoding) and handling missing values.
- 📉 **Exploratory Data Analysis (EDA):** Deep analysis of feature correlations and media impact on total sales.
- 🤖 **Predictive Modeling:** Multi-model implementation (Linear Regression, Decision Trees, Random Forest) to find the best performing algorithm.
- 📏 **Performance Metrics:** Evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and $R^2$ Score.
